# Keccak256 Hash Tool

A simple Python script that takes user input and converts any word into a Keccak256 hash using the `pycryptodome` library.  
The script also displays a banner using `pyfiglet` for a nicer terminal experience.

## Features
- Converts any word into a Keccak256 hash
- Clean terminal banner using pyfiglet
- Lightweight and easy to run
